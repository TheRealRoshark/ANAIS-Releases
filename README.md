# ANAIS Releases

This public repository hosts the ANAIS Stable update feed and downloadable application releases. The ANAIS application source remains in a separate private repository.

- Stable feed: `feed-stable-v1.json` on `main`.
- Installer assets: GitHub Releases, tagged by application version.
- Publication order: publish and verify an installer asset before a feed offers it.
- Content packs use the same feed after their own review and publication.

The initial preview.5 feed reports the manually migrated application as current and advertises no content update.
